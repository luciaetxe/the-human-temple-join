# The Human Temple 🌿

A simple, responsive website for a non-profit association dedicated to spreading yoga philosophy through movement and mindful living.

## ✨ What it is

This project is a static website designed as a presentation space for *The Human Temple* association. It includes sections to explain the project’s vision, and invite people to join the community.

## 🔧 Technologies used

- HTML
- CSS (including Flexbox and simple animations)

## 🎯 My role

This was a personal project to practice front-end web development while creating something meaningful and close to my heart. I designed and built the layout from scratch, focusing on:

- Clean and minimal design
- Responsive structure for different devices
- Clear content hierarchy

## 📚 What I learned

- Better use of CSS positioning and layout techniques
- Structuring semantic HTML
- Writing readable, maintainable code
- Thinking from a user’s perspective

## 💡 Next steps

I plan to extend this site with:
- A contact form
- Multilingual versions
- Possible integration with a CMS for updates
